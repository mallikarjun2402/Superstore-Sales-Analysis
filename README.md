# 🛒 Superstore Sales Analysis

## 📌 Project Overview
End-to-end sales analysis on 9,994 records using 
Excel, SQL, Python and Power BI.

## 🛠️ Tools Used
- Microsoft Excel
- MySQL
- Python (Pandas, Matplotlib, Seaborn)
- Power BI

## 📊 Key Insights
1. West region has highest sales
2. Technology is most profitable category
3. November is peak sales month
4. Copiers are top selling product
5. Consumer segment buys the most
6. High discounts reduce profit

## 📁 Files
- Superstore Analysis.xlsx — Excel dashboard
- Superstore SQL Queries.sql — SQL queries
- Superstore_Python_Analysis.ipynb — Python code
- Superstore Dashboard.pbix — Power BI dashboard

## 🏆 Results
- Total Sales: $2.30M
- Top Region: West
- Top Category: Technology
- Top Product: Copiers
